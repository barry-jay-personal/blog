# A Big Step
## Barry Jay
### 2026-11-07

Where did the time go? I was working on the next phase of typed tree calculus and it got away from me! Anyway, I now have a substantial new work, called *Typing Rules Become Programs in Tree Calculus* in the repository [typing-rules-as-programs](https://github.com/barry-jay-personal/typing-rules-as-programs). There is a lot going on but the basic idea is very simple. Make typing be combinatory. That is, if f:F and u:U then the application of f to u is typed by applying F to U as F # U. All of the complexity of typing is captured by the intensional program that defines type application. It supports several forms of polymorphism, and this without type variables or quantifiers. Even function types are a sideshow! 

The appendix describes my ambitions in graphical form as the Leibniz project. Maybe LLMs can help it happen. 

I read yesterday that Professor Futamura (of projections fame) has been hired by Oracle. And Erik Meijer mentions a well-funded verification startup. So things are moving!
